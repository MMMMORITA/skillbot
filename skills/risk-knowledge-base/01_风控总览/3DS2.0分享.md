## 适用场景
需要理解 3DS2.0 是什么、如何实现、相比 3DS1.0 的优势及未来演进方向时参考。适用于 3DS 相关支付流程/验证体验的科普与方案讨论，以及理解无感（frictionless）流程与挑战（challenge）流程差异、3DS 验证结果参数（eci、CAVV 等）含义。

## 核心概念
- 3DS2.0：国际卡组织提供的网上交易安全验证服务（3DS）升级版，用于解决 3DS1.0 痛点、提升支付体验。
- Directory Server（DS）：认证 3DS Server 与 ACS、路由消息、校验 3DS Server/SDK/Requestor、定义程序规则、Onboarding、维护协议版本与 3DS Method URL。
- Access Control Server（ACS）：由发卡行控制，包含认证规则；校验卡号/设备类型是否符合 3DS 认证条件、认证持卡人或确认账户信息。
- 无感流程（frictionless）：发卡行对低风险交易免 OTP 直接完成 3DS 验证。
- 挑战流程（challenge）：需持卡人在发卡行页面完成验证。
- 验证结果参数：eci（07/06/05、00/01/02）、Authentication status（Y/N/U/A/R）、cavv（仅可用一次）、xid（3DS1）、dsTransactionId（3DS2），供 issuer 关联交易。

## 规则 / 策略要点
- eci 与 Authentication status 对应关系：05/02 对应验证成功（Y）；06/01 对应尝试验证（A）；07/00 对应验证失败（U/N/R）。
- 发卡行支持前提：上述 3DS2.0 优势均需发卡行支持 3DS2 才生效；若发卡行不支持（如日本、韩国、巴西、中国等地支持度较低），则回退到 3DS1.0 流程。
- 未来内部方向：将 3DS 验证流程与交易流程解耦，验证完成后取得参数（eci/Authentication status/cavv/xid/dsTransactionId）再传给 Payin 渠道扣款，以减少各卡类 Payin 的重复 3DS 接入。

# 3DS2.0是什么？

简单理解，3DS2.0就是由国际卡组织提供的针对网上交易的安全验证服务（3DS）的升级版。目的是解决3DS1.0的相关痛点，以提供给用户更好的支付体验。

**Directory Server**

The DS performs a number of functions that include:

• Authenticating the 3DS Server and the ACS

• Routing messages between the 3DS Server and the ACS

• Validating the 3DS Server, the 3DS SDK, and the 3DS Requestor

• Defining specific programme rules (for example, logos, time-out values, etc.)

• Onboarding 3DS Servers and ACSs

• Maintaining ACS and DS Start and End Protocol Versions and 3DS Method URLs



**Access Control Server**

The ACS contains the authentication rules and is controlled by the Issuer. ACS functions include:

• Verifying whether a card number is eligible for 3-D Secure authentication

• Verifying whether a Consumer Device type is eligible for 3-D Secure authentication

• Authenticating the Cardholder or confirming account information

# 3DS2.0的优势是什么？

**① 无感流程（frictionless流程）**

发卡行通过收集更多信息，针对部分低风险（由发卡行风控系统判断）的交易，在3DS2.0模式下提供无感流程，即用户无需在发卡行验证页面进行OTP验证，也可完成3DS验证流程。

据Visa数据预估，这种快速，轻松的结帐流程可以使持卡人受益，用户主动放弃率预估可降低多达66％。



**② 无线端适配性提升**

在3DS2.0模式中，发卡行页面大小可以进行放缩（可通过传参配置），以更好的适应无线端页面展示。



**③ 收集更多数据**

在3DS2.0模式中，通过“设备信息收集”步骤，发卡行可以收集更多（10倍）的数据，可以更准确的对交易风险进行判断。

据Visa数据，95%的交易可以直接付款成功（即进行无感流程），持卡人被盗卡风险降低40%。



注：上述优势均需要在发卡行支持3DS2的前提下才可生效，如果发卡行不支持3DS2.0（日本，韩国，巴西，中国等国目前3DS2.0发卡行端支持度并不高），则发卡行会仍走到3DS1.0流程上。

**【收益】**

1. 可依据3DS验证结果，对交易进行更适合PIPO or 业务方的逻辑处理；
2. 后续无须再接入所有卡类Payin的3DS方案，减少重复开发；

## 外部
